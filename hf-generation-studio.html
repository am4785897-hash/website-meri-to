Uses the Hugging Face serverless Inference API (https://api-inference.huggingface.co/models/<model-id>) directly from your browser with a fetch() call — there is no server in between, so your token never leaves this tab except to talk to Hugging Face. Video-capable serverless models are limited; if a model returns a permission or "not supported" error, try a different model ID or an Inference Endpoint you've deployed yourself. Cold models can take 20–60s to warm up on first request — the tray will say so and retry automatically.
